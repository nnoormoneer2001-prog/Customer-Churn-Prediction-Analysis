# 📊 Customer Churn Prediction & Analysis

A Machine Learning project focused on analyzing customer behavior and predicting customer churn using Python.

## 📌 Project Overview

This project aims to analyze customer purchasing behavior and predict whether customers are likely to leave or continue using a service.

The project applies data cleaning, exploratory data analysis, feature engineering, and machine learning techniques to identify patterns associated with customer churn.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost
- Google Colab

## ⚙️ Project Workflow

1. **Data Exploration:** Understanding the dataset and its features.
2. **Data Cleaning:** Handling missing values and checking duplicate records.
3. **Exploratory Data Analysis (EDA):** Exploring customer behavior and data patterns.
4. **Feature Engineering:** Creating new features to improve model performance.
5. **Model Training:** Training and comparing Decision Tree, Random Forest, and XGBoost models.
6. **Model Evaluation:** Evaluating model performance using Accuracy, Precision, Recall, and F1-Score.
7. **Feature Importance:** Identifying the most influential features in the XGBoost model.

## 📈 Model Results

The best recorded result in the experiments was achieved by the tuned XGBoost model.
